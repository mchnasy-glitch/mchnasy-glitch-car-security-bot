# 🛡 بازوی پیام‌رسان بله برای ثبت سفارش خدمات ضدسرقت خودرو

این پروژه یک بازوی (ربات) حرفه‌ای، راست‌به‌چپ (RTL) و کاملاً فارسی برای **پیام‌رسان بله (Bale)** است که با استفاده از کتابخانه پرقدرت **aiogram 3** و پایگاه داده سبک و پرسرعت **SQLite** توسعه داده شده و از سرور رسمی `https://tapi.bale.ai` پشتیبانی می‌کند.

همچنین امکان تغییر پیام‌رسان به تلگرام تنها با تغییر یک متغیر در فایل کانفیگ وجود دارد.

---

## 📌 مزایای اجرای ربات در پیام‌رسان بله
1. **عدم نیاز به فیلترشکن و پروکسی**: بله در داخل کشور کاملاً در دسترس است و بدون قطعی و با سرعت بسیار بالا کار می‌کند.
2. **پشتیبانی از سرورهای داخلی ایران (VPS ایران)**: می‌توانید ربات را روی ارزان‌ترین سرورهای لینوکس داخل کشور (آروان‌کلاد، پارس‌آنلاین، آسیاتک و ...) بدون افت سرعت یا مسدودیت اجرا کنید.
3. **سازگاری کامل با استانداردهای aiogram 3**: سرور `tapi.bale.ai` پروتکل استاندارد ربات‌ها را پوشش داده و با معماری مدرن aiogram 3 هماهنگ است.

---

## 🚀 راهنمای گام‌به‌گام راه‌اندازی در پیام‌رسان بله

### مرحله ۱: ساخت بازو و دریافت توکن در بله

1. وارد اپلیکیشن **پیام‌رسان بله** شوید.
2. به شناسه **[@BotFather](https://ble.ir/botfather)** در بله پیام دهید.
3. دستور `/newbot` را ارسال نمایید.
4. یک نام فارسی و یک شناسه انگلیسی (با پسوند `bot`) برای بازوی خود تعیین کنید.
5. توکن دریافتی (رشته‌ای شبیه `123456789:ABCdefGh...`) را کپی کنید.

### مرحله ۲: دریافت شناسه عددی اکانت مدیر (`ADMIN_ID`)

1. در بله به ربات **[@userinfobot](https://ble.ir/userinfobot)** یا بخش اطلاعات کاربری پیام دهید تا شناسه عددی (ID) اکانت خود را دریافت کنید.
2. این عدد همان شناسه شما برای دسترسی به پنل مدیریت با دستور `/admin` است.

---

### مرحله ۳: راه‌اندازی و اجرای بازو در سرور یا کامپیوتر

1. مطمئن شوید پایتون ۳.۱۰ یا بالاتر نصب است:
   ```bash
   python3 --version
   ```

2. وارد پوشه پروژه شده و محیط مجازی بسازید:
   ```bash
   cd telegram_bot
   python3 -m venv venv
   source venv/bin/activate  # در لینوکس و مک
   # venv\Scripts\activate   # در ویندوز
   ```

3. کتابخانه‌های مورد نیاز را نصب کنید:
   ```bash
   pip install -r requirements.txt
   ```

4. فایل `.env` را از روی نمونه ایجاد کنید:
   ```bash
   cp .env.example .env
   ```
   فایل `.env` را باز کرده و مقادیر دریافتی از بله را وارد کنید:
   ```ini
   MESSENGER=bale
   BALE_API_URL=https://tapi.bale.ai
   BOT_TOKEN=توکن_دریافتی_از_بات_فادر_بله
   ADMIN_ID=شناسه_عددی_شما_در_بله
   DB_PATH=bot_database.db
   ```

5. بازو را اجرا کنید:
   ```bash
   python3 main.py
   ```
   با اجرای دستور فوق، پایگاه داده SQLite و داده‌های اولیه خودروها و خدمات خودکار ایجاد شده و پیامی مبنی بر روشن شدن بازو به اکانت بله شما ارسال می‌گردد.

---

## ⚠️ چرا گیت‌هاب اکشنز (GitHub Actions) برای این ربات مناسب نیست؟
- بازو برای پاسخگویی در لحظه (Instant Response) نیاز به کانکشن زنده و دائمی Long Polling دارد.
- کران‌جاب‌های GitHub Actions حداقل هر ۵ دقیقه یک بار اجرا می‌شوند و گاهی تا ۱۵ الی ۳۰ دقیقه تأخیر دارند.
- گیت‌هاب فرآیندهای پس‌زمینه مداوم را متوقف کرده و اکانت را مسدود می‌کند.
- **بهترین گزینه**: یک سرور مجازی لینوکس (VPS) کوچک در ایران یا خارج کشور با اجرای پایدار توسط `systemd`.

---

## 🛠 اجرای خودکار ۲۴ ساعته با Systemd در لینوکس

فایل `bot.service` موجود در پروژه را در مسیر سیستم کپی و فعال کنید:

```bash
sudo cp bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable bot.service
sudo systemctl start bot.service

# مشاهده لاگ زنده:
sudo journalctl -u bot.service -f
```

## 📂 ساختار فایل‌های پروژه
```text
telegram_bot/
│
├── .env.example         # نمونه فایل تنظیمات (بله و تلگرام)
├── requirements.txt     # کتابخانه‌ها (aiogram 3, aiosqlite, ...)
├── README.md            # راهنمای فارسی پیام‌رسان بله
├── Dockerfile           # ساخت ایمیج داکر
├── docker-compose.yml   # راه‌اندازی با کانتینر داکر
├── bot.service          # سرویس لینوکس systemd
│
├── main.py              # تنظیم session به tapi.bale.ai و اجرای بازو
├── config.py            # بارگذاری امن متغیرها
├── database.py          # مدیریت SQLite و اسنپ‌شات دائمی سفارشات
├── states.py            # ماشین FSM مشتری و مدیر
├── keyboards.py         # کیبوردهای اینلاین با چک‌باکس پویا (☑/◻)
│
└── handlers/
    ├── __init__.py
    ├── customer.py      # مسیر مشتری: نام، اعتبارسنجی شماره، انتخاب خدمات و تأیید
    └── admin.py         # پنل اختصاصی مدیر (/admin): خودروها، خدمات و سفارش‌ها
```
